本项目面向现代城市交通管理中的核心痛点：在极端天气（如暴雨积水）、交通早晚高峰、大型活动等高压场景下，城市路网的脆弱点往往难以被及时发现，且缺乏科学的预警与治理依据。为此，本项目开发了一套“城市交通韧性治理智能分析平台”。系统基于开源真实路网数据，利用自主设计的图神经网络（Graph Transformer）构建路口级风险评估模型。平台不仅能够输出精确的节点风险指数，还能通过拓扑关系计算道路联动风险，并自动生成“建议增设排水泵站”、“建议优化信号灯”或“纳入日常巡查”等具有极强实操性的分级治理建议。结合 WebGL 高性能可视化看板，系统为城市交通管理部门提供从研判到决策的一站式支持。# Traffic_Projict
